# کلاسینو — نسخهٔ آزمایشی P2P بدون پایتون

## راه‌اندازی
این نسخه فقط HTML/CSS/JavaScript است و Python/FastAPI لازم ندارد. فایل‌های پوشهٔ `web` را در مخزن GitHub قرار بده و GitHub Pages را فعال کن. برای دوربین و میکروفون حتماً از HTTPS استفاده کن.

## ورود به کلاس
1. دبیر نقش «دبیر / استاد» را انتخاب کند، روی «ساخت کلاس» بزند و سپس «ورود به کلاس» را انتخاب کند.
2. کد ۶ رقمی را به دانش‌آموزان بدهد.
3. دانش‌آموزان همان کد را با نقش «دانش‌آموز» وارد کنند و وارد شوند.
4. اجازهٔ دوربین و میکروفون را بدهند. اول با دو دستگاه تست کن، سپس ۴ نفر را امتحان کن.

## محدودیت‌ها
- این نسخه آزمایشی از سرویس هماهنگ‌کنندهٔ عمومی PeerJS برای پیدا کردن دستگاه‌ها استفاده می‌کند؛ تصویر و صدا از طریق WebRTC مستقیم بین دستگاه‌ها منتقل می‌شوند. بنابراین سرور اختصاصی پایتون لازم نیست، اما کاملاً بدون سرویس اینترنتی نیست.
- دسترسی به PeerJS/STUN ممکن است در بعضی شبکه‌ها محدود باشد؛ برای برخی اتصال‌ها TURN لازم می‌شود. عملکرد روی همهٔ شبکه‌ها تضمین نشده و باید با دستگاه‌های واقعی آزمایش شود.
- کد کلاس احراز هویت امن نیست؛ عمومی منتشرش نکن. گزارش حضور دائمی و ذخیرهٔ مرکزی در این نسخه وجود ندارد. ضبط ویدئو غیرفعال است.


نسخهٔ بازطراحی‌شده: چیدمان کاشی‌ها واکنش‌گرا، تختهٔ آموزشی، ارسال فایل کوچک از دبیر و کنترل صدای/تصویر محلی هر شرکت‌کننده. ارسال فایل در این نسخهٔ آزمایشی تا ۱٫۵ مگابایت است. برای ارتباط واقعی، سرویس عمومی PeerJS ممکن است در بعضی شبکه‌ها در دسترس نباشد؛ تماس بین چند دستگاه در شبکه‌های مختلف هنوز نیازمند آزمایش عملی است.
